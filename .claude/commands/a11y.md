# /a11y — Accessibility audit

Run a full accessibility audit on the current app.

## Checks

1. **Landmarks**: Verify `<header>`, `<main>`, `<nav>`, `<section>` all have `aria-label`.
2. **Labels**: Every `<input>`, `<select>`, `<textarea>` has a `<label for>` or `aria-label`.
3. **Radio groups**: Each radio has individual `aria-label` (e.g. "3 stars").
4. **Modal**: Focus moves into dialog on open, Tab is trapped, focus restores on close.
5. **Live regions**: Toast container has `aria-live="polite"`, errors have `role="alert"`.
6. **Keyboard**: Tab through entire app — every interactive element is reachable and operable.
7. **Reduced motion**: `prefers-reduced-motion: reduce` collapses all animations.
8. **Color contrast**: Text meets WCAG AA (4.5:1 for normal text, 3:1 for large).
9. **Semantic HTML**: Use `<button>` not `<div onclick>`, `<nav>` not `<div class="nav">`.
10. **Hidden content**: Use `.sr-only` for visually-hidden but screen-reader-accessible text.

## Output

Report each check as ✅ PASS or ❌ FAIL with specific fix needed.
